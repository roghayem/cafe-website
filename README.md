# ☕ Cafe Website

A modern, responsive, and visually appealing Cafe Website built using HTML, CSS, and JavaScript. This project showcases a professional coffee shop website with elegant design, smooth navigation, featured menu sections, and a fully responsive user experience across all devices.

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/roghayem/cafe-website.git
```

2. Open the project folder:

```bash
cd cafe-website
```

3. Open `index.html` in your browser.
